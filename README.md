# سامانه هزینه ماموریت

نرم‌افزار دسکتاپ (ویندوز) برای ثبت، پیگیری و گزارش‌گیری هزینه‌های ماموریت اداری؛ ساخته‌شده با **Next.js 15** و **Electron** به‌صورت کاملاً کامپوننت‌محور، راست‌به‌چپ و با تقویم شمسی.

## امکانات

### ثبت ماموریت
- انتخاب شعبه از فهرست پیش‌فرض (**رامسر، نوشهر، رویان**) یا ورود دستی محل جدید (با امکان افزوده‌شدن به فهرست شعب)
- موضوع ماموریت، تاریخ شروع و پایان، هزینه **رفت**، **برگشت** و **غذا**
- انتخاب تاریخ با **تقویم شمسی** به همراه مشخص‌بودن **تعطیلات رسمی** (سال‌های ۱۴۰۴ تا ۱۴۰۶ + جمعه‌ها + تعطیلات دلخواه)
- محاسبه **خودکار** تعداد روز ماموریت، تعداد روزهای تعطیل و روزهای کاری

### گردش وضعیت هزینه
```
انجام شده  ──[ثبت در EPM + کد غذا و کد ایاب و ذهاب]──►  بارگذاری شده  ──[پرداخت شد]──►  پرداخت شده
```
- دکمه **ثبت در EPM**: دو کد ثبت (غذا و ایاب و ذهاب) دریافت و وضعیت را به «بارگذاری شده» تغییر می‌دهد
- دکمه **پرداخت شد**: وضعیت را به «پرداخت شده» تغییر می‌دهد

### آمار و گزارش
- جمع هزینه در هر سه وضعیت (انجام شده / بارگذاری شده / پرداخت شده)
- **مجموع طلب از شرکت** (انجام‌شده + بارگذاری‌شده) و **مجموع پرداخت‌شده توسط شرکت**
- تفکیک هزینه بر اساس شعبه و روند ماهانه
- گزارش ماموریت‌ها در **بازه زمانی دلخواه**، با یا بدون نمایش هزینه‌ها، خروجی **CSV** و **چاپ/PDF**

### مدیریت اسناد
- انتخاب اسناد به‌صورت جداگانه برای **ایاب و ذهاب** و **غذا**
- اسناد در مسیر انتخاب‌شده در تنظیمات کپی می‌شوند؛ برای هر ماموریت پوشه‌ای با تاریخ روز هزینه ساخته می‌شود:

```
<مسیر انتخابی>
└── 14050705
    ├── ایاب و ذهاب
    │   └── taxi-receipt.pdf
    └── غذا
        └── restaurant.jpg
```

## معماری پروژه

```
app/                 صفحه و لایه‌بندی Next.js (static export)
components/
  ├── ui/            اجزای پایه: Modal, Card, Field, MoneyInput, StatusBadge, Icons …
  ├── layout/        Sidebar, TopBar, Toasts
  ├── date/          JalaliDatePicker (تقویم شمسی با تعطیلات)
  ├── dashboard/     StatCards, StatusDonut, BarList, DashboardView
  ├── missions/      MissionForm, MissionTable, MissionFilters, EpmDialog, DocsDialog
  ├── reports/       ReportView
  └── settings/      SettingsView, BranchesEditor, HolidaysEditor
lib/                 jalali, holidays, types, filters, format, bridge
providers/           AppProvider (وضعیت سراسری + ذخیره‌سازی)
electron/            main.js (پنجره، IPC، مدیریت فایل) و preload.js
```

- بدون هیچ وابستگی runtime؛ تقویم شمسی، نمودارها و آیکون‌ها همگی داخلی پیاده‌سازی شده‌اند (حجم کمینه)
- داده‌ها در فایل `data.json` داخل پوشه `%APPDATA%/Mission Expenses` ذخیره می‌شود
- ارتباط رابط کاربری با سیستم فایل فقط از طریق `contextBridge` و IPC امن انجام می‌شود

## اجرا در حالت توسعه

```bash
npm install
npm run dev        # Next.js + Electron
```

## ساخت خروجی ویندوز

```bash
npm run dist       # خروجی در پوشه release/
```

انتشار خودکار: با ثبت یک تگ `v*` روی مخزن، گردش‌کار GitHub Actions فایل‌های `exe` را ساخته و در Release منتشر می‌کند.
